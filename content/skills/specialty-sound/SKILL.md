# Specialty: sound

Dispatch: worker at least, senior-worker for design (a new sound or family with no picked direction), never weak-worker; reads the repo profile's **Branches and worktrees**, **Build and test**, **Shared resources** and **Audio**.

`creative.md` (`../specialty-tech-art/creative.md` from this folder), `measuring.md` beside this file, first.

**You cannot hear.** No hearing claims, no improvement from source strength: measurement or source only. Listening model's verdict: cited evidence, not hearing.

1. Inputs: sound/family by game id; event ("a hammer killing a player", not "a meaty thud"); FEEL block; replace or propose (default propose); live sources. No **Audio** direction (default profile has none): stop, say so.
2. First, scratch sound brief per sound: event, what player must understand, frequency, mix neighbours.
3. New sound/family, no direction: Step 0 (`creative.md`), 5-10 short directions (source; transient, body, tail; envelope); cheap procedural sketch.
4. Read, don't listen: library tags, descriptions, game-audio notes; cite.
5. Three named options per sound (`creative.md` "Takes"), different brief answers: intent, layers, envelope, numbers, drop-in path, listen-for.
6. Sources in `measuring.md` order.
7. Prepare; measure every clip before/after vs whole set (`measuring.md`); look at each spectrogram.
8. Critique from numbers, spectrograms (`creative.md`); page (clips playable, before/after, spectrogram + numbers beside replaced); commit (skill builder).

## Generated audio

Hosted generator: profile **Audio** "Generated audio:" line (models, style/variety controls, analysis/listen tools); unnamed: stop, say so. Local: `measuring.md` source 4.
1. Take budget in clips (one submission may return several): brief or owner's paid approval; spent: stop, report.
2. Takes differ on purpose (model, style prompt, variety/weirdness, negative style), one change each; never resubmit same settings.
3. Check each take (analysis/listen tools) vs brief: complete, length as requested; real ending or fade, no mid-phrase cut; no flat/repeated sections; seamless loop point if looping; after prepare, `measuring.md` numbers by name.
4. Drop failures, near-duplicates by numbers, spectrogram, listening verdict; never by file name or prompt.
5. Exact settings recorded per profile record rule: pick reproducible.
6. Owner shortlist (default three): distinct, checked, each with what varied, what check found.

## Report

Page path/URL first; sound brief; options (intent, source, why not cheaper); before/after table; spectrogram notes; critique's three weaknesses; **what the owner should listen for, as a question the owner can answer**; licence, where recorded; branch, commit. Shortlist ends "Which of these three, or none?"
