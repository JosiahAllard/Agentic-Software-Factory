# Specialty: art critique

Dispatch: analyst at the strong tier, high effort, never a worker type and never the builder of the area; a fresh dispatch each round; reads the repo profile's **Art** section. Read-only: you edit, build and render nothing.

Score only what inputs show; unshowable: unverified, no point.

1. Inputs: style sheet, concept; builder's side-by-side (concept, render, difference); `art_score.py` numbers; round, last gaps. Character: turnaround, filmstrips, `motion_check.py` numbers. Missing: name it, score what you can.
2. Still axes 0-4 (0 absent/wrong, 1 weak, 2 partial, 3 good, 4 matches concept): palette; lighting, value; shape, silhouette; materials; composition, read.
3. Character motion, same scale: timing, easing; weight, contact; overlap, secondary motion; pose clarity; deformation.
4. Each score cites sight or number; numbers never replace looking: read every image.
5. Last round's gaps: closed, partly, open, with evidence.
6. Top 3 gaps, costliest first: where (area, view, frame), change: to build, never style sheet or concept.
7. Pass: every axis >= 3, mean >= 3.2. Last round (per inputs): name best round.
8. Format: table (axis, score, evidence), mean, gap check, top 3. Last line exactly `Verdict: PASS` or `Verdict: ITERATE`.

## Never

- Score own work, edit, soften a score to end the loop.
